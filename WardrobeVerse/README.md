# Teju's Wardrobe — Smart AI Fashion & Outfit Studio

A responsive digital fashion platform and AI outfit styling studio built with HTML, Vanilla CSS, and modern JavaScript.

## ✨ Features

- **AI Virtual Outfit Studio**: Interactive dressing room slots (Tops, Outerwear, Bottoms, Footwear, Accessories, Bags) with real-time Style Harmony scoring.
- **Smart 1-Click AI Presets**: Instant lookbook generation for Casual Weekend, Executive Office, Night Glam, Festive Ethnic, Campus Cool, and Job Interview.
- **Dynamic AI Auto-Complete**: Intelligently finishes incomplete outfit canvases based on style and occasion pairing.
- **30+ Curated Catalog Items**: Rich product cards with quick-view modal previews, occasion tags, and gender filters.
- **Shopping Bag & Checkout Flow**: Slide-out cart drawer with live item counter badge, quantity adjustment, subtotal calculation, and instant checkout.
- **My Wardrobe & Favorites**: Save custom-built ensembles with thumbnails and bookmark favorite pieces with instant local storage persistence.
- **Filter & Search Engine**: Real-time keyword search, category pills, occasion filters, gender selector, and price/name sorting.
- **Luxury Fashion Aesthetics**: Dark velvet obsidian & champagne gold theme, glassmorphic frosted cards, smooth micro-interactions, and responsive layout across mobile, tablet, and desktop.

## 🚀 How to Run

1. Open `index.html` in any modern web browser, or serve locally:
   ```bash
   python -m http.server 8080
   ```
2. Navigate to `http://localhost:8080` in your browser.
